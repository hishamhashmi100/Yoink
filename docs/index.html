How to install

Takes about a minute. Yoink isn't on the Play Store, so Android asks a couple of extra questions.

  1. Tap “Download for Android” If your browser asks whether to keep the file, tap Download or Download anyway.
  2. Open the downloaded file Tap Open in the notification, or find yoink in your Files → Downloads folder.
  3. Allow installing from your browser Android will say it can't install apps from this source. Tap Settings, turn on Allow from this source, then go back.
    You only need to do this once. You can turn it off again after installing.
  4. Tap Install If Google Play Protect shows a warning, tap More details → Install anyway. It warns about every app that doesn't come from the Play Store.
  5. Open Yoink once Allow notifications so you can see download progress. That's it.

Questions

 

Is it safe?

Yoink is open source: anyone can read every line of the code on GitHub. The APK is built and signed automatically by GitHub from that public code, and each release lists SHA-256 checksums so you can confirm your file wasn't changed.

Why isn't it on the Play Store?

Google Play doesn't allow apps that download from YouTube, so Yoink is distributed here instead, the same way many open-source Android apps are.

Does it need a server or an account?

No. Everything happens on your phone. There's no sign-in, no tracking and no ads.

Downloads stopped working. What do I do?

YouTube changes things often. Open Yoink → Settings → Update downloader. That fixes it almost every time. If not, check this page for a newer version.

Where do my videos go?

Into Yoink's Library. In Settings you can also choose to save them to your gallery (Movies/Yoink and Music/Yoink).

How do I update Yoink?

Download the latest version from this page and install it over the old one. Your library is kept.
